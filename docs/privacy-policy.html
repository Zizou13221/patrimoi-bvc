En bref : PatriMoi ne vend pas vos données, n'affiche pas de publicités, et ne partage aucune information financière avec des tiers commerciaux. Vos données patrimoniales sont chiffrées sur votre appareil et sur nos serveurs.

1Données collectées

1.1 Données de compte

Lorsque vous créez un compte PatriMoi, nous collectons :

  • Adresse email — identifiant unique, réinitialisation de mot de passe
  • Prénom et nom — affichage dans l'application et vos rapports PDF
  • Mot de passe — stocké sous forme hachée (jamais en clair)

1.3 Données de marché (non personnelles)

PatriMoi récupère automatiquement des données publiques pour valoriser vos actifs :

  • Cours des actions BVC (Bourse de Casablanca) — via scraping GitHub Actions
  • Prix de l'or (LBMA) — mis à jour quotidiennement
  • Taux de change BAM (bkam.ma) — 18 devises
Ces données de marché sont publiques et anonymes. Elles ne contiennent aucune information personnelle et sont mises en cache dans une table market_cache partagée, sans lien avec votre compte.

1.4 Données techniques minimales

Automatiquement collectées lors de l'utilisation de l'application :

  • Journaux d'erreurs (anonymisés) — pour corriger les bugs
  • Aucun identifiant publicitaire (IDFA non utilisé)
  • Aucun cookie de tracking

3Stockage et sécurité

3.1 Hébergement cloud

Vos données sont stockées sur Supabase (PostgreSQL), dans une région Europe de l'Ouest (Irlande), soumise au RGPD européen.

  • Chaque utilisateur ne peut accéder qu'à ses propres données (Row Level Security)
  • Les connexions sont chiffrées en TLS 1.3
  • La base de données est chiffrée au repos (AES-256)

3.2 Stockage local sur l'appareil

  • MMKV AES-128 — stockage chiffré des préférences et cache local
  • iOS Keychain — session Supabase, code PIN (haché SHA-256 + sel 128 bits), données biométriques
  • Attribut iOS WHEN_UNLOCKED_THIS_DEVICE_ONLY — les données Keychain ne sont pas sauvegardées sur iCloud

3.3 Code PIN

Le code PIN 6 chiffres est stocké uniquement sur l'appareil (Keychain iOS local), sous forme hachée. Il n'est jamais transmis à nos serveurs. Un PIN oublié nécessite une réinitialisation des données locales.

Note : PatriMoi est actuellement distribué avec un compte Apple Developer Personnel. Le profil de provisionnement expire tous les 7 jours et doit être renouvelé manuellement. Ceci n'affecte pas la sécurité de vos données.

4Partage avec des tiers

PatriMoi ne partage vos données personnelles avec aucun tiers commercial. Les seuls sous-traitants techniques impliqués sont :

Sous-traitant Rôle Localisation
Supabase Inc. Base de données, authentification Irlande (EU)
Apple Inc. Distribution iOS (App Store), paiements in-app États-Unis
Aucune donnée financière ou patrimoniale n'est jamais partagée avec des banques, courtiers, assureurs ou tout autre tiers.

5Durée de conservation

  • Données de compte & patrimoine — conservées tant que votre compte est actif
  • Snapshots historiques — conservés tant que votre compte est actif (supprimés avec le compte)
  • En cas de suppression du compte — toutes les données sont supprimées de nos serveurs dans les 30 jours
  • Données locales — supprimées quand vous désinstallez l'application ou réinitialisez l'appareil

Vous pouvez demander la suppression immédiate de votre compte directement depuis Paramètres → Supprimer mon compte dans l'application.

6Vos droits (loi 09-08 / CNDP)

Conformément à la loi 09-08 relative à la protection des personnes physiques à l'égard du traitement des données à caractère personnel au Maroc, vous disposez des droits suivants :

Droit Comment l'exercer
Accès Toutes vos données sont visibles dans l'application. Export CSV/PDF disponible dans Paramètres.
Rectification Modifiable directement dans l'application (profil, données patrimoniales)
Suppression Paramètres → Supprimer mon compte (suppression immédiate et irréversible)
Opposition Contactez-nous par email (voir section 10)
Portabilité Export CSV depuis Paramètres → Exporter en CSV
PatriMoi s'engage à se conformer à la loi 09-08 relative à la protection des données à caractère personnel au Maroc. Pour toute question relative au traitement de vos données, contactez-nous à l'adresse indiquée en section 10.

7Mode Démo

PatriMoi propose un mode démo 100 % local : aucun compte requis, aucune donnée transmise à nos serveurs. Toutes les données sont stockées uniquement sur l'appareil.

En mode démo, aucun email ni aucune information personnelle n'est collecté.

8Mineurs

PatriMoi est destiné aux personnes de 18 ans et plus. Nous ne collectons pas sciemment de données concernant des mineurs. Si vous pensez qu'un mineur a créé un compte, contactez-nous pour le supprimer.

9Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité pour refléter des évolutions techniques ou légales. En cas de modification substantielle, vous serez informé via une notification dans l'application.

La date de dernière mise à jour est indiquée en haut de ce document. L'utilisation continue de PatriMoi après modification vaut acceptation de la nouvelle politique.
